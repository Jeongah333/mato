# 강아지 똥피하기

GitHub Pages에 올리는 순수 정적 웹게임입니다.

## GitHub에 올릴 파일

이 폴더 안의 파일들을 GitHub 저장소 최상단에 올리세요.

- index.html
- src/app.js
- src/styles.css
- .nojekyll

중요: `smok-github` 폴더 자체를 올리는 것이 아니라, 폴더 안의 파일들을 저장소 첫 화면에 바로 올리는 것이 가장 쉽습니다.

## GitHub Pages 켜기

1. GitHub 저장소에서 Settings 클릭
2. Pages 클릭
3. Source를 `Deploy from a branch`로 선택
4. Branch는 `main`, Folder는 `/root` 선택
5. Save 클릭
6. 1~3분 뒤 `https://깃허브아이디.github.io/저장소이름/` 으로 접속
